
# EventHub - Event Management Website

## 1. Project Description

EventHub is a simple event management website developed using HTML, CSS, and JavaScript.

The website allows users to browse upcoming events, view event details, book tickets, and contact the event management team.

## 2. Technologies Used

- **HTML5** - Used to structure the web pages.
- **CSS3** - Used to style the website and make it responsive.
- **JavaScript** - Used to add interactivity and handle form validation.
- **Local Storage** - Used to save booking information in the browser.

## 3. Website Pages

The website contains five main pages:

1. **Home Page (index.html):** Introduces EventHub and displays featured events.
2. **Events Page (events.html):** Displays available events with search and category filtering.
3. **Event Details Page (event-details.html):** Shows information about a selected event.
4. **Registration Page (register.html):** Allows users to fill in their details and book event tickets.
5. **Contact Page (contact.html):** Displays contact information and a contact form.

## 5. How to Run the Project

1. Download or copy the EventHub project folder.
2. Open the project folder in a code editor such as Visual Studio Code.
3. Open a terminal inside the project folder.
4. Run the following command:

```bash
python3 -m http.server 8000
```

5. Open a web browser and visit:

```text
http://localhost:8000
```

6. The EventHub homepage will appear.

Alternatively, open `index.html` directly in a web browser.

## 6. Main Features

- Responsive website design.
- Event browsing and searching.
- Event category filtering.
- Dynamic event details.
- Ticket booking and price calculation.
- Booking confirmation and printable receipt.
- Contact form with basic validation.
- Browser-based booking storage.


## 7. Conclusion

EventHub demonstrates the use of HTML, CSS, and JavaScript in developing a multi-page interactive website. It provides a simple platform for browsing events and demonstrating basic ticket booking functionality.
